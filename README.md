# Simple Text Message

A simple, lightweight web-based text messaging application built with HTML, CSS, and JavaScript.

## Features

- **Message Display**: View sent and received messages in a clean, chat-like interface
- **Dynamic Messaging**: Add new messages to the conversation in real-time
- **Message Types**: Toggle between sending and receiving messages
- **Live Clock**: Real-time clock display in the top-left corner
- **Timestamp**: Each message automatically gets a timestamp
- **Keyboard Support**: Press Enter to send messages quickly
- **Responsive Design**: Clean and simple UI that works on various screen sizes

## Description

This is an HTML-based application that allows you to send and receive messages. Messages are displayed on the screen in a chat-like interface. Messages don't send anywhere—they simply display locally in the browser.

## Usage

1. Open `text_message.html` in your web browser
2. Type your message in the input field
3. Choose the message type (Send/Receive) from the dropdown
4. Click "Send" or press Enter to add the message to the conversation

## Technologies

- **HTML5**: Structure and markup
- **CSS3**: Styling and layout
- **JavaScript (Vanilla)**: Interactivity and dynamic functionality

## How It Works

- **Message Display**: Messages appear differently based on type:
  - **Sent**: Blue background, aligned to the right
  - **Received**: White background, aligned to the left
- **Clock**: Updates every second to display the current time
- **Input Handling**: Supports keyboard shortcuts (Enter key) and form input

## Getting Started

Simply clone or download this repository and open `text_message.html` in any modern web browser.

```bash

cd simple_text_message
```
